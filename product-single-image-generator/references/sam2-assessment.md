# SAM 2 guided segmentation assessment

Status on 2026-10-23: **research only; no SAM 2 inference adapter or model checkpoint is installed by this skill**. Current observations come from assistant/human annotation. Do not label them SAM 2 detections. Read this reference only when planning or evaluating optional segmentation.

[Meta's project page](https://ai.meta.com/research/sam2/) describes selecting objects in images/video using clicks, boxes or masks. [The official repository](https://github.com/facebookresearch/sam2) provides `SAM2ImagePredictor` and checkpoints, including SAM 2.1 variants. This workflow needs single-image guided segmentation; video tracking is unnecessary.

Proposed role in this product workflow: the reviewer selects the sold product or assigned detail, SAM 2 estimates its mask, code computes bounds/retained pixels/overlap, and visual review checks correctness and design. Segmentation alone does not establish identity, correct hardware, complete off-frame parts, copy accuracy or visual balance. A mask's predicted quality score is not a calibrated probability of product correctness.

The [official image predictor](https://github.com/facebookresearch/sam2/blob/main/sam2/sam2_image_predictor.py) accepts foreground/background point labels, XYXY boxes and low-resolution mask inputs, and returns masks at original image size plus quality predictions. Convert this skill's normalized prompts to the predictor's documented coordinates; preserve EXIF orientation. Its mask-input interface expects low-resolution logits from prediction, not an arbitrary full-size PNG passed unchanged. Disambiguate the strap from the watch, skin, reflections and background using targeted guidance. Preserve evidenced holes; do not automatically fill them as segmentation noise.

A future adapter should bind source SHA-256, model/checkpoint/config versions, prompts and coordinate conversion, selected mask hash and any corrections. Review the mask overlay first. Only a verified mask can supply observed regions; ambiguous masks remain `REVIEW_REQUIRED`. A detail task protects the assigned detail, not every visible product pixel. Pixel-mask overlap can refine conservative box tests, but cannot replace content-completeness review. These are integration requirements, not implemented mask checks.

[Official installation instructions](https://github.com/facebookresearch/sam2/blob/main/INSTALL.md) primarily document Linux/PyTorch/CUDA; they also allow skipping the CUDA extension with limited postprocessing. The inspected local runtime is macOS arm64 and has neither `torch` nor `sam2`. CPU/MPS compatibility and speed here have not been tested. Install/infer in a separate runtime only after choosing that deployment; keep model weights and PyTorch outside skill ZIPs. No weights were downloaded and no SAM 2 inference was run for this assessment.

A web-chat skill import does not by itself provide this model runtime. Use actual available segmentation tools or an explicitly configured external/local runtime; otherwise continue the existing guided visual annotation and mark segmentation unavailable. Before making SAM 2 a default, compare masks against human annotations on thin straps, connectors, holes, skin contact, occlusion and reflections from the real-image baseline.
