## Modules

For every Gallery or Premium A+ independent image task record: sales task, buyer question, target view/pose, product references, reviewed prior candidates, required locks, claim IDs, copy, output requirements (including exact pixels when specified), and prohibited changes.

Also record the catalog template ID/revision, normalized product/copy boxes, concrete composition, visible hardware and evidenced states, human limb ownership/contact/occlusion when present, and evidence-backed operating states/direction for any arrows or operation copy.

For grouped A+ also record each page module's ID, display type, content role, buyer question and ordered image-task IDs. Keep page-module count separate from image count. The A+ profile has a revisable 7-group/9-image structural seed and normally plans 13 independent 1464 × 600 images, uses the reference page only for structure, and hands separate files to the design team for assembly. Record any local additions or affected IDs in revisions; do not import the reference seller's product, claims or visual style.

## Set-level QA

- Coverage of each assigned buyer question and page responsibility; no unrelated substitutions
- Distinct sales job and deliberate visual idea per image
- Hierarchy, depth, integrated graphics/copy and coherent composition variation against creative briefs
- Recognizable person/action/environment in full lifestyle tasks; intentional wrist crops only for local detail
- Balanced evidence-supported views
- Strongest supported selling points appear early
- Copy readable at the requested display size (no additional mobile rendition unless requested)
- Coherent palette/type/icon/lighting/model direction
- No unsupported claims
- No candidate used outside its approved scope
- All required modules accepted
- Each module has a matching full-resolution visual-QA report, including anatomy/contact/hardware/operation checks as applicable
- Delivery table links each output, template, QA record, human decision and unresolved item
