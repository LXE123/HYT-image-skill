# 自主执行、按需取参与内部试图

复用已有产品资料和当前授权；AI 负责设计选择、必要取参、生成、自查与有限修正。受众细分、配色、字体、机位和可逆构图由 AI 拟定为设计假设，无需用户逐项批准。只有影响当前交付的必要产品事实或范围无法确定时集中询问，其余任务继续。

## 按问题取参

先确定一个需要解决的具体设计问题，再查已有输入；不足时定向搜索合适的厂商、Amazon 或设计来源。无需每张联网，也不把找灵感交回用户。实际查看像素后才能记录视觉结论；标题和摘要只用于定位。记录来源/日期、已查看图片、借鉴元素、适用图片 ID 和原因。保留能改变当前决定的参考，够用即停。

同一路径直接重试一次仍遇到权限、验证或超时问题，就换来源。都不可用时用已查看资料继续可执行的设计并说明限制。不能虚构已看过图片。参考只提供指定设计元素，不能补造本产品结构、参数、功能或认证；风格影响程度也不是生成工具的精确权重。

具体设计与审核按 [visual-direction.md](visual-direction.md) 执行。仅需进一步组合摄影/图文方法时才读 [风格融合](product-led-style-integration.md)；预设目录是可选资源。

## 内部检查后继续授权任务

主图模式采用 [Gallery 前两张联合检查](amazon-planning.md#opening-pair-inspect-first-inherit-identity-rather-than-pose)：先执行已有白底正反展示子图并对照原图检查，后续传递产品状态，不传递立式构图；多款式排列可自由设计并按内容验收。两张仍计入原套图，不增加图数或默认人评关卡；这不改变 A+ 的试图策略。

完整套图先选少量代表子图（按风险选 1–3 张，不额外增加总数）检查实际效果，覆盖本套的主要设计/结构风险；一张白底主图不足以检验多种表达。自查后继续其他已授权子图，无须等待小样人评。用户明确只要小样或要求先选方向时，按其范围停下。

构图/层级问题修设计；事实/结构问题回原始证据。保留候选与历史，沿用单图技能的重试上限及修订规则；不让用户修提示词，不反复增强装饰来掩盖事实错误。候选保持 `PENDING_REVIEW`，人工接受必须来自真实决定。

测试时简记产品/输入版本、图片/QA 路径、参考来源、修正次数、实际用户操作/等待及原因、剩余问题与人工反馈。事实、内容任务、设计效果分别评估；流程通过和实际视觉验收分别报告。无实际图片/人评时，明确相应效果未验证。
