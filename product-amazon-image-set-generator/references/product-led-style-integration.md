# 产品主导的风格融合

按当前产品、品牌/受众、使用情境和图片职责选取光线、空间、尺度、材质与图文关系。沿用 `adaptive`、共享 `visual_system`、逐图 `creative_brief` 和既有 QA；不新增风格选择门槛、固定坐标或批准流程。单图设计方法见 [art-direction.md](../../product-single-image-generator/references/art-direction.md)。

| 图片职责 | 风格的作用 | 必须清楚的证据 |
|---|---|---|
| 介绍 | 用光影、形态、空间或情境吸引注意 | 实际售卖对象及核心特征 |
| 卖点 | 用证据与图文关系解释理由 | 真实买家问题及依据 |
| 材质/结构 | 延续光线色调，改变观察尺度 | 纹理、部件与连接关系 |
| 选择/适配 | 统一字体标记，收敛装饰 | 可比视图和已验证选择信息 |
| 操作 | 用统一语言组织动作和顺序 | 真实状态、接触与操作方向 |
| 场景 | 用人物、动作和环境传达生活气质 | 自然尺度的产品和可信使用 |

通常让一项视觉关系主导图片，其他元素为它服务；相关多面板/细节可沿同一阅读路径组织。共享气质通过尺度、密度、焦点和场景变化形成节奏。材质或适配品牌不自动绑定风格，样稿的一次认可也不成为其他客户/产品的默认偏好。

只使用当前选定的相关参考。实际查看后登记来源为 `STYLE_REFERENCE`；本图通过 `style_source_ids` 和可选 `reference_influences` 指定借鉴元素、程度与原因。附上实际选中图片；无参考时自主设计，不自动加载历史实验图。参考不转移产品、文案或功能事实。

具体字段及设计验收以 [visual-direction.md](visual-direction.md) 为准。审核看实际焦点、层级、氛围与图文是否服务本图；装饰不能遮挡产品、改变结构或替代解释与选择信息。
